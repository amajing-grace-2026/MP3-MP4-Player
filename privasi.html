Kebijakan Privasi

Amajing Player oleh Amajing Labs · Berlaku sejak 25 November 2026

Amajing Player adalah aplikasi web untuk memutar file musik/video, YouTube, Google Drive, dan radio. Halaman ini menjelaskan data apa yang dipakai aplikasi dan bagaimana caranya. Singkatnya: kami tidak punya server untuk menyimpan data kamu. Semua berjalan di browser perangkatmu sendiri.

1. Data yang disimpan di perangkatmu

  • File musik/video yang kamu tambahkan, daftar putar (playlist), link YouTube/Google Drive/radio, serta pengaturan seperti volume disimpan di penyimpanan browser (IndexedDB & localStorage) di perangkatmu.
  • Data ini tidak dikirim ke Amajing Labs. Kamu bisa menghapusnya kapan saja dengan tombol "Kosongkan Daftar", menghapus playlist, atau menghapus data situs di pengaturan browser.

2. Berbagi playlist lewat link

  • Saat kamu menekan "Bagikan", isi playlist (judul lagu, ID video YouTube, ID file Google Drive, link radio) dimasukkan ke dalam link itu sendiri. Link tidak disimpan di server kami.
  • Siapa pun yang menerima link bisa melihat isi playlist tersebut. File lagu yang ada di HP-mu tidak ikut dibagikan.

3. Akses Google Drive (opsional)

Jika kamu memakai fitur "Upload ke Google Drive", aplikasi meminta izin Google dengan cakupan drive.file. Dengan izin ini aplikasi hanya bisa mengakses file dan folder yang dibuat oleh aplikasi atau yang kamu pilih sendiri lewat jendela pemilih Google. Aplikasi tidak bisa melihat file lain di Drive-mu.

Izin tersebut dipakai hanya untuk: (1) membuat folder atau memakai folder yang kamu pilih, (2) meng-upload lagu yang kamu pilih ke folder itu, dan (3) mengatur folder/file tersebut menjadi "Siapa saja yang memiliki link" agar playlist bisa didengar orang yang kamu kirimi link.

  • Token akses Google hanya disimpan sementara di memori browser selama aplikasi terbuka, tidak dikirim ke Amajing Labs, dan tidak disimpan permanen.
  • File yang di-upload tetap milikmu dan tersimpan di Google Drive-mu. Kamu bisa menghapusnya atau mengubah pengaturan berbaginya langsung di Google Drive.
  • Kamu bisa mencabut izin kapan saja di myaccount.google.com/permissions.
  • Penggunaan dan pengiriman informasi yang diterima dari Google API oleh Amajing Player mengikuti Google API Services User Data Policy, termasuk persyaratan Limited Use.
    Amajing Player's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Pastikan kamu berhak membagikan lagu yang kamu upload dan buka untuk umum. Tanggung jawab atas isi file ada pada pemilik Drive.

4. Layanan pihak ketiga

  • YouTube: video diputar lewat pemutar resmi YouTube, yang tunduk pada Kebijakan Privasi Google.
  • Google Drive: lagu dari link Drive diambil langsung dari server Google.
  • Radio: pencarian stasiun memakai radio-browser.info, dan siaran diambil langsung dari server stasiun radio.
  • Iklan: aplikasi menampilkan iklan dari jaringan iklan pihak ketiga, yang dapat memakai cookie atau data teknis perangkat sesuai kebijakan mereka sendiri.
  • Masukan & dukungan: tautan "Kirim masukan" membuka Google Form, dan "Traktir kopi" membuka Saweria. Data yang kamu isi di sana diatur oleh layanan tersebut.

5. Anak-anak

Aplikasi ini tidak ditujukan untuk mengumpulkan data anak-anak, dan kami tidak mengumpulkan data pribadi siapa pun.

6. Perubahan & kontak

Kebijakan ini bisa diperbarui sewaktu-waktu, dan tanggal berlakunya akan diubah di atas. Pertanyaan atau permintaan bisa dikirim lewat formulir masukan.
